# Rueda Libre

## Descripción
Sitio web de Rueda Libre, emprendimiento de Medellín que alquila bicicletas y organiza recorridos guiados. Versión v1.0: sitio informativo con HTML semántico, formulario validado y hoja de estilos única (`css/styles.css`).

## Tecnologías
- HTML5 semántico
- CSS3 (variables, grid, flexbox)
- Google Fonts (Poppins e Inter)
- Git y GitHub
- VS Code + Live Server

## Estructura
```
rueda-libre/
├── index.html
├── pages/        (recorridos, tarifas, contacto)
├── assets/       (images, icons, videos)
├── css/
├── js/
├── docs/bitacora.txt
├── README.md
└── .gitignore
```

## Instalación
1. `git clone <url-del-repositorio>`
2. Abrir la carpeta en VS Code.
3. Clic derecho en `index.html` > **Open with Live Server**.

## Navegación
Inicio → Recorridos → Tarifas → Contacto (menú común en todas las páginas).
