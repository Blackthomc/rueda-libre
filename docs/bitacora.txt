BITACORA - RUEDA LIBRE v0.2
==========================

--- MINIRETO 5: Estructura semantica ---
Fecha: (completar)
Actividad: Reestructurar las paginas con header, nav (lista), main, section, article, aside, address, footer y enlace "Saltar al contenido".
Problema: Las paginas usaban estructura generica y los lectores de pantalla no podian saltar entre regiones.
Solucion: Un unico h1 por pagina, secciones con aria-labelledby, nav con aria-label, main con id para el enlace de salto.
Prueba realizada: Revisar el arbol de accesibilidad en Chrome DevTools (pestana Accessibility) y navegar por regiones.
Resultado: Cada pagina expone landmarks banner, navigation, main y contentinfo.

--- MINIRETO 6: Formulario de reservas ---
Fecha: (completar)
Actividad: Construir el formulario con el control correcto para cada dato.
Problema: Un campo de texto para todo no valida ni ayuda al teclado movil.
Solucion: text (nombre), email, tel, select (servicio), radio en fieldset (bicicleta), date, time, number, textarea y checkbox. Cada control con label for/id y atributo autocomplete cuando aplica.
Prueba realizada: Tocar cada label y comprobar que el foco pasa al campo; abrir en celular y revisar el teclado.
Resultado: Todos los campos tienen etiqueta asociada y el teclado se adapta al tipo.

--- MINIRETO 7: Validacion nativa y teclado ---
Fecha: (completar)
Actividad: Validar con required, minlength, pattern, min/max y probar solo con teclado.
Pruebas (dato enviado -> resultado esperado):
  1. Formulario vacio                    -> bloquea y marca el primer campo obligatorio.
  2. Nombre "Al"                         -> bloquea (minimo 3 caracteres).
  3. Correo "juan@"                      -> bloquea (correo invalido).
  4. Celular "12345"                     -> bloquea (pattern 3 + 9 digitos).
  5. Celular "3001234567"                -> acepta.
  6. Fecha anterior al 28/10/2026        -> bloquea (min).
  7. Hora 19:00                          -> bloquea (max 17:00).
  8. Personas 0 u 11                     -> bloquea (min 1, max 10).
  9. Sin elegir bicicleta                -> bloquea (radio required).
 10. Sin aceptar tratamiento de datos    -> bloquea (checkbox required).
 11. Todos los datos correctos           -> envia.
Teclado: Tab recorre en orden logico; flechas cambian el radio; Espacio marca el checkbox; Enter envia.
